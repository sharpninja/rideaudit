# RideAudit.Shared.Ui

Shared Avalonia UI 12 controls for the Android capture client and the desktop court viewer.

License: GPL-2.0-or-later (see repository `LICENSE` and `NOTICE`).

The Avalonia framework packages are upstream MIT. RideAudit UI source in this project is not relicensed as MIT or Apache-2.0.

Screens follow `docs/ux/` (capture) and `docs/ux/review-app/` (review): role select, Bluetooth discovery, driver clock, passenger spider graph, seal status, and the desktop fail-closed verification / escrow / timeline path.

This library does not call Lyft private APIs.
