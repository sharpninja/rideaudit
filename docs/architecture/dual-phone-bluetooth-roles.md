# Dual-phone Bluetooth roles

Sequence:
1. Bluetooth discovery between approved phones.
2. Driver-rider pairing with explicit roles.
3. Driver phone coordinates session clock, start/stop, and submission orchestration.
4. Passenger phone performs video sync, stream joining/compositing, and realtime telematics overlay (spider graph).

This is RideAudit device pairing, not a Lyft Bluetooth API.
